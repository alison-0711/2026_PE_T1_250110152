# 2026_PE_T1_250110152

Es una página web educativa de Probabilidad y Estadística que presenta tres ejemplos estadísticos con contexto real: datos discretos, continuos y cualitativos. Cada ejemplo incluye 100 datos, una tabla de frecuencia y cinco gráficas generadas con Python (histograma, barras, polígono, ojiva y pastel).
